# Профиль бота для @BotFather

Аватарка: `avatar.png` (640×640). Команды ниже отправляй @BotFather по очереди.

**/setname** — Водичка — трекер воды

**Username** (при /newbot, должен заканчиваться на bot, свободность проверит Telegram): `vodichka_water_bot`, `vodichka_app_bot`, `drink_vodichka_bot`

**/setabouttext** (до 120 символов, сейчас 88)
Пей воду вовремя 💧 Норма, напоминания, серии и коллекция морских существ. Жми «Открыть»!

**/setdescription** (до 512 символов, сейчас 298)
Водичка помогает пить достаточно воды каждый день.

💧 Дневная норма и быстрые кнопки
🔔 Напоминания
🔥 Серии дней подряд
🎁 Кейс за выполненную норму: собирай коллекцию морских существ от ракушки до легендарной русалки
💎 Pro: темы, рыбка-питомец, карта 30 дней

Нажми «Открыть» и сделай первый глоток!

**/setcommands**
start - Открыть Водичку

**/setuserpic** — отправь `avatar.png`

**Кнопка запуска** — /mybots → бот → Bot Settings → Menu Button → Configure menu button → адрес фронтенда, название кнопки «Открыть»
